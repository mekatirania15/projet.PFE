# Différence entre Git et GitHub
## Git :
  Git est un logiciel de gestion de versions ** Version Control System **qui permet de suivre les modifications effectuées dans les fichiers d'un projet.
### Il permet de :
•	Enregistrer les différentes versions d'un projet grâce aux commits.
•	Suivre les modifications apportées aux fichiers.
•	Revenir à une ancienne version du projet.
•	Travailler avec des branches sans modifier le projet principal.
•	Travailler localement sur son ordinateur, même sans connexion Internet.
## GitHub :
  GitHub est une plateforme en ligne qui permet d'héberger des projets Git et de faciliter le travail collaboratif entre plusieurs développeurs.
### Il permet de :
•	Stocker les projets Git sur Internet.
•	Partager les projets avec d'autres personnes.
•	Travailler en équipe sur un même projet.
•	Suivre les modifications apportées par les collaborateurs.
•	Sauvegarder les projets à distance.
##  La différence entre Git et GitHub :
La principale différence est que ** Git ** est un logiciel installé sur l'ordinateur qui permet de gérer les versions d'un projet, tandis que** GitHub ** est une plateforme en ligne qui permet d'héberger et de partager les projets gérés avec Git.
